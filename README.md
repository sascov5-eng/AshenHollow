# Ashen Hollow

iOS action-platformer prototype built with Swift + SpriteKit.

## Current goal

First stabilize:
1. Movement
2. Jumping
3. Physics and collisions
4. Comfortable controls on a real iPhone

## Platform

- iOS
- Landscape Left / Landscape Right
- Swift + SpriteKit

> Prototype project. Original characters, art, music, dialogue, and world design will be created independently and will not copy protected material from other games.
