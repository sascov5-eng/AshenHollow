# Ashen Hollow v1.6 Trials Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a single v1.6 IPA that adds a compact timed-trials shell and fixes v1.5 interaction, combat, healing, HUD, and moving-platform defects.

**Architecture:** Preserve the current v1.4 source and v1.5 build-time integration pipeline. Add focused v1.6 runtime support plus a final build-time patch script that runs after the v1.5 transforms. Keep trial/menu state in SwiftUI and local `UserDefaults`, while `GameSceneV14` owns the active timed run and gameplay feedback.

**Tech Stack:** Swift 6 compiler, SwiftUI, SpriteKit, Foundation/UserDefaults, Python 3 integration scripts, GitHub Actions macOS 15.

**Spec:** `docs/superpowers/specs/2026-09-05-v1.6-trials-design.md`

## Global Constraints
- `CFBundleShortVersionString = 1.6`
- `CFBundleVersion = 2`
- `CFBundleIdentifier = app.ashenhollow.prototype`
- Landscape left/right only.
- Visible label: `v1.6 • ИСПЫТАНИЯ • БОЙ + UI`.
- Preserve camera zoom 1.75 and Little Axion 480×480 at y = -8.
- No ads, analytics, accounts, online services, cloud saves, purchases, or graphics settings.
- Settings/results are local only.
